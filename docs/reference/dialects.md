What each of the six dialects supports, and what it refuses. Every refusal
raises `DialectError` while the statement builds, never in the database.

Guide: [SQL Dialects](/dialects).

## `Dialects`

In `sustained.dialects`.

| Member | Engine |
| --- | --- |
| `Dialects.DEFAULT` | ANSI SQL, and SQLite in practice |
| `Dialects.POSTGRES` | PostgreSQL |
| `Dialects.MSSQL` | Microsoft SQL Server |
| `Dialects.PRESTO` | Presto, Trino |
| `Dialects.ATHENA` | AWS Athena |
| `Dialects.DUCKDB` | DuckDB |

`Dialects.get_compiler(dialect)` returns the compiler instance. Set a dialect
with `Model.set_dialect()`, or pass one to `Migrator(dialect=...)`.

## Drivers and placeholders

The connection's parameter style must match the dialect's placeholder, or
execution fails at the driver.

| Dialect | Driver | Placeholder | Identifier quoting |
| --- | --- | --- | --- |
| `DEFAULT` | `sqlite3` | `?` | none |
| `POSTGRES` | `psycopg`, `psycopg2` | `%s` | `"name"` |

| `PRESTO` | `trino` | `?` | `"name"` |

## Query features

A blank cell means the feature works.

| Feature | Default | Postgres | DuckDB | MSSQL | Presto | Athena |
| --- | --- | --- | --- | --- | --- | --- |
| `LIMIT` / `OFFSET` | | | | needs `orderBy()`, compiles to `OFFSET ... FETCH` | `OFFSET` before `LIMIT` | `OFFSET` before `LIMIT` |
| `top()` | raises | raises | raises | | raises | raises |
| `distinctOn()` | raises | | | raises | raises | raises |
| `qualify()` | raises | raises | | raises | raises | raises |
| `for_update()` | raises | | raises | raises | raises | raises |
| `explain()` | | | | raises | | |
| `ILIKE` | emulated | native | native | emulated | emulated | emulated |
| `WITH RECURSIVE` | | | | plain `WITH` | | |
| Booleans | `TRUE` / `FALSE` | | | `1` / `0` | | |

Emulated `ILIKE` compiles to `LOWER(col) LIKE LOWER(pattern)`, so it never
raises.

## Write features

| Feature | Default | Postgres | DuckDB | MSSQL | Presto | Athena |
| --- | --- | --- | --- | --- | --- | --- |
| Upserts | `ON CONFLICT` | `ON CONFLICT` | `ON CONFLICT` | `MERGE` | raises | `MERGE`, Iceberg only |
| `returning()` | | | | raises | raises | raises |
| `create_table_as()` | | | | raises | | raises when `temporary=True` |

The MSSQL messages name the alternative: `OUTPUT` for RETURNING,
`SELECT ... INTO` for CTAS.

## Schema features

| Feature | Default | Postgres | DuckDB | MSSQL | Presto | Athena |
| --- | --- | --- | --- | --- | --- | --- |
| `autoincrement` | rowid alias | `GENERATED BY DEFAULT AS IDENTITY` | raises | `IDENTITY(1,1)` | raises | raises |
| Constraints | | | | | | none, raises |
| ALTER COLUMN type | no, rebuilds | | | | no | `CHANGE COLUMN`, widening only |
| ALTER COLUMN nullability | raises | | | | raises | raises |
| `USING` cast hints | raises | | ignored | ignored | raises | raises |
| Rename column | | | | `sp_rename` | | raises |
| Rename table | | | | `sp_rename` | | raises |
| Indexes | | | | | | raises |
| Table options | raises | raises | raises | raises | raises | |

The default dialect cannot alter a column, so migration generation rebuilds
the table instead: create new, copy rows, replace. A rebuild is not
reversible, so a migration containing one has no down step. Columns and
indexes the models do not declare are carried across the rebuild unless
`allow_drops=True`. An index on an expression cannot be introspected, so a
rebuild loses it; recreate it by hand.

## Migration behaviour

| Behaviour | Default | Postgres | DuckDB | MSSQL | Presto | Athena |
| --- | --- | --- | --- | --- | --- | --- |
| Transactions | | | | | | none |
| `rehearse()` | | | | refuses | refuses | refuses |
| Advisory lock | none | `pg_advisory_lock` | none | `sp_getapplock` | none | none |

Only the three dialects whose schema changes roll back may rehearse against
the real database. The rest need `scratch=True` and a throwaway database.

Without transactions, Athena runs each step bare and never calls rollback, so
a failing multi-step migration can leave partial changes. It writes a
failed-attempt row so the interrupted run is visible.

SQLite and DuckDB have no advisory lock because they serialize writers
themselves. Athena has none to take, so run one migrator at a time there.

## Introspection

The default dialect reads SQLite's PRAGMA tables. Every other dialect reads
`information_schema`. Where the constraint views are unavailable,
introspection degrades to column data alone rather than failing.
